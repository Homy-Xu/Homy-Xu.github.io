I am an undergraduate student at the School of Computer Science, Shanghai Jiao Tong University, and a member of the Zhiyuan Honors Program.

My research interests mainly lie in coding foundation models, long-horizon agents, and self-improving AI. I am currently focusing on agent memory, parametric memory, coding-model post-training, and recursive self-improvement — especially how models and agents can accumulate, update, and reuse experience over long-term interaction. I also have a background in database systems and data management, which led me to study memory from a data-management perspective and later move toward agentic coding, long-horizon memory, and model self-improvement.

  • Coding Foundation Models & Long-Horizon Agents — agentic coding, persistent execution history, repository-scale software engineering
  • Agent & Parametric Memory — representation, storage, extraction, retrieval, routing, update, maintenance, and learned memory
  • Coding-Model Post-Training & Self-Improvement — task construction, trajectory curation, capability evaluation, recursive improvement
  • Database Systems & Data Management — database–LLM interaction, NL2SQL / Text-to-SQL, data-management foundations for memory systems

MemTrace: State-Consistent Memory for Long-Horizon Coding Agents

Hongming Xu, Le Zhou, ZhongHe Jin, Xiang Zhang, Bo Tang, Zhiyu Li, Xuanhe Zhou, Juncheng Zhang

Under review · ICLR 2027 First author

A state-consistent memory system that combines structured execution traces with repository grounding to validate historical evidence before reuse. Evaluated across three software-engineering benchmarks and two coding-agent harnesses, consistently improving the primary metric over native memory strategies.

arXiv Repository

Dial: A Knowledge-Grounded Dialect-Specific NL2SQL System

Xiang Zhang, Hongming Xu, Le Zhou, Wei Zhou, Xuanhe Zhou, Guoliang Li, Yuyu Luo, Changdong Liu, Guorun Chen, Jiang Liao, Fan Wu

PVLDB 2026 Co-first author (listed second)

Dial studies dialect-specific NL2SQL for heterogeneous database systems, where different SQL dialects introduce distinct syntax, functions, and execution constraints. I contributed to natural-language preprocessing, dialect-aware logical planning, and knowledge retrieval — including the design and initialization of HINT-KB, iterative feedback and semantic correction, and failure analysis.

arXiv Code

Are We Ready For An Agent-Native Memory System?

Wei Zhou, Xuanhe Zhou, Shaokun Han, Hongming Xu, Guoliang Li, Zhiyu Li, Feiyu Xiong, Fan Wu

Under review · VLDB Agent memory / data management systems

A systematic study of agent memory across representation and storage, extraction, retrieval/routing, and maintenance. We evaluate task effectiveness, retrieval fidelity, dynamic-update robustness, long-term stability, and runtime cost across diverse workloads.

arXiv Code

Tensor-Network Physical Pages for Quantum-Ready Data Management

 

QCDKM 2026 Quantum database / approximate data management

TN-Page is a tensor-network physical-page representation for approximate data management and quantum backends. We study workload-aware bucketization, tensorization, factorization, and backend-aware encoding, evaluating fidelity, compression, qubit usage, and gate depth.
