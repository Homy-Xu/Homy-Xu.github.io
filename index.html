About me关于我

I am an undergraduate at Shanghai Jiao Tong University and a member of the Zhiyuan Honors Program. I am currently a research intern at MemTensor, mentored by Juncheng Zhang (Tsinghua University). Previously, I worked with Prof. Xuanhe Zhou at Theseus Lab.

我目前就读于上海交通大学计算机学院，是致远荣誉计划成员。目前在 MemTensor 担任研究实习生，导师为 Juncheng Zhang（清华大学）；此前在 Theseus Lab 跟随周煊赫教授开展研究。

My research centers on coding foundation models, long-horizon agents, and self-improving AI. I study how models and agents accumulate, update, and reuse experience, with a focus on agent memory, parametric memory, coding-model post-training, and recursive self-improvement. My background in database systems led me to approach memory from a data-management perspective.

我的研究兴趣主要是代码基础模型、长程智能体与自我改进 AI，关注模型与智能体如何在长期交互中积累、更新和复用经验。当前重点包括智能体记忆、参数记忆、代码模型后训练与递归自我改进。数据库系统的研究背景，也让我习惯从数据管理的角度理解记忆。

MemTrace: State-Consistent Memory for Long-Horizon Coding Agents

Hongming Xu, Le Zhou, ZhongHe Jin, Xiang Zhang, Bo Tang, Zhiyu Li, Xuanhe Zhou, Juncheng Zhang

Under review at ICLR 2027ICLR 2027 审稿中First author第一作者

Keeping memory useful as code changes. MemTrace connects immutable execution traces with the current repository state, checking historical evidence before reuse. Evaluated on three software-engineering benchmarks and two coding-agent harnesses.

让记忆随代码演化保持有效。MemTrace 将不可变的执行轨迹与当前仓库状态关联，在复用历史证据前检查其有效性，并在三个软件工程基准、两种代码智能体框架上进行评测。

Dial: A Knowledge-Grounded Dialect-Specific NL2SQL System

Xiang Zhang*, Hongming Xu*, Le Zhou, Wei Zhou, Xuanhe Zhou, Guoliang Li, Yuyu Luo, Changdong Liu, Guorun Chen, Jiang Liao, Fan Wu

PVLDB 2026Co-first author共同第一作者

Knowledge-grounded SQL generation across database dialects. Dial combines dialect-aware logical planning, retrieval from HINT-KB, and execution feedback with semantic correction.

面向不同数据库方言的知识增强 SQL 生成。Dial 结合方言感知逻辑规划、HINT-KB 知识检索，以及执行反馈和语义修正，支持跨数据库的自然语言查询。

Are We Ready For An Agent-Native Memory System?

Wei Zhou, Xuanhe Zhou, Shaokun Han, Hongming Xu, Guoliang Li, Zhiyu Li, Feiyu Xiong, Fan Wu

Under review at VLDBVLDB 审稿中

A systematic study of agent memory through a data-management lens: representation and storage, extraction, retrieval, and maintenance. We evaluate effectiveness, retrieval fidelity, update robustness, long-term stability, and runtime cost.
