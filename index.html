About me关于我

I am an undergraduate in Information Security at the School of Computer Science, Shanghai Jiao Tong University, and a member of the Zhiyuan Honors Program. I am currently a research intern at MemTensor, mentored by Juncheng Zhang (Tsinghua University). Previously, I worked with Prof. Xuanhe Zhou at Theseus Lab.

我目前就读于上海交通大学计算机学院信息安全专业，是致远荣誉计划成员。目前在 MemTensor 担任研究实习生，导师为 Juncheng Zhang（清华大学）；此前在 Theseus Lab 跟随周煊赫教授开展研究。

My research began with database systems and data management, studying how large language models interact with structured data and heterogeneous databases. This led me to approach memory as a data-management problem: how agents represent, store, retrieve, update, and maintain experience. In Are We Ready For An Agent-Native Memory System?, I explored these questions through system decomposition and systematic evaluation.

我的研究始于数据库系统与数据管理，关注大语言模型如何与结构化数据及异构数据库交互。这段经历让我开始将记忆视为一个数据管理问题：智能体应如何表示、存储、检索、更新和维护经验？在 Are We Ready For An Agent-Native Memory System? 中，我通过系统模块划分与系统性评测探索了这些问题。

Building on this foundation, I now focus on coding foundation models, long-horizon agents, and memory for self-improving AI. At MemTensor, I work on coding-model post-training and memory mechanisms for long-horizon coding agents. I am especially interested in how external and parametric memory help models and agents accumulate, consolidate, and reuse experience over long-term interaction.

在此基础上，我目前关注代码基础模型、长程智能体，以及服务于自我改进 AI 的记忆机制。在 MemTensor，我参与代码模型后训练，并研究长程代码智能体的记忆机制。我尤其关注外部记忆与参数记忆如何帮助模型和智能体在长期交互中积累、整合和复用经验。

MemTrace: State-Consistent Memory for Long-Horizon Coding Agents

Hongming Xu, Le Zhou, ZhongHe Jin, Xiang Zhang, Bo Tang, Zhiyu Li, Xuanhe Zhou, Juncheng Zhang

Under review at ICLR 2027ICLR 2027 审稿中First author第一作者

Memory that stays aligned with changing code. MemTrace treats long-horizon coding memory as a state–memory alignment problem. Immutable Memory Traces carry explicit repository provenance; a Memory Trace Graph (MTG), a Repository State Graph (RSG), and trace-to-entity bindings connect execution history to the current repository so historical evidence can be validated before reuse.

让记忆与持续变化的代码保持一致。MemTrace 将长程代码智能体的记忆建模为状态与记忆的对齐问题。不可变的 Memory Traces 保存明确的仓库来源信息；Memory Trace Graph（MTG）、Repository State Graph（RSG）及轨迹与实体间的绑定，将执行历史关联到当前仓库，以便在复用历史证据前验证其有效性。

  • Evaluated on DeepSWE, SWE-EVO, and SWE-Milestone under two coding-agent harnesses with the same backbone model; improved the primary metric over Native memory in every completed benchmark × harness setting.在相同基础模型下，基于两种代码智能体框架评测 DeepSWE、SWE-EVO 和 SWE-Milestone；在已完成的各组基准与框架组合中，主要指标均优于对应的 Native 记忆策略。
  • 57.0% of file-bound Memory Traces were exposed to later repository modifications, motivating explicit checks of historical evidence against the current state.57.0% 的文件关联 Memory Traces 所对应的文件在后续执行中发生过修改，说明有必要依据当前状态检查历史证据。

Dial: A Knowledge-Grounded Dialect-Specific NL2SQL System

Xiang Zhang*, Hongming Xu*, Le Zhou*, Wei Zhou, Xuanhe Zhou, Guoliang Li, Yuyu Luo, Changdong Liu, Guorun Chen, Jiang Liao, Fan Wu

PVLDB 2026Co-first author · listed second共同第一作者 · 列第二

Knowledge-grounded NL2SQL across database dialects. Dial addresses differences in SQL syntax, functions, and execution constraints. It combines natural-language logical query plans (NL-LQP) and dialect-sensitive intermediate representations with retrieval from HINT-KB, iterative execution feedback, and semantic correction.

面向异构数据库方言的知识增强 NL2SQL。Dial 针对不同 SQL 方言的语法、函数与执行约束差异，结合自然语言逻辑查询计划（NL-LQP）、方言敏感的中间表示、HINT-KB 知识检索、迭代执行反馈与语义修正。

Are We Ready For An Agent-Native Memory System?

Wei Zhou, Xuanhe Zhou, Shaokun Han, Hongming Xu, Guoliang Li, Zhiyu Li, Feiyu Xiong, Fan Wu

Under review at VLDBVLDB 审稿中

Agent memory through a data-management lens. This study decomposes memory into representation and storage, extraction, retrieval and routing, and maintenance. We compare heterogeneous architectures on task effectiveness, retrieval fidelity, robustness to dynamic updates, long-horizon stability, and runtime cost.

从数据管理视角理解智能体记忆。这项工作将记忆系统划分为表示与存储、提取、检索与路由、维护四类模块，并从任务效果、检索保真度、动态更新鲁棒性、长程稳定性和运行成本等方面比较异构记忆架构。
